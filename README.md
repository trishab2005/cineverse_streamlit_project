# 🎬 CineVerse — Movie Discovery & Recommendation Platform

CineVerse is a **MySQL + Python + Streamlit** project that demonstrates how a relational database can power a real-life movie discovery and recommendation platform.

The project is designed as a **user-facing movie platform**, not as a traditional management system. Users can discover movies, filter them by different attributes, explore actors, rate movies, write reviews, maintain favorites, and view analytical insights generated using SQL.

---

## ✨ Features

### 🏠 Home Dashboard

- Displays the total number of movies, users, ratings, and streaming platforms.
- Shows a list of trending movies based on popularity.

### 🔎 Discover Movies

Users can:

- Search movies by title.
- Filter by genre.
- Filter by language.
- Filter by release-year range.

### 🎭 Genre Explorer

- Select a genre and retrieve matching movies.
- Uses the MySQL stored procedure `GetMoviesByGenre`.
- Displays IMDb ratings in a bar chart.

### 🎬 Actor Explorer

- Browse the available actors.
- View movies associated with a selected actor.
- Displays the actor's character, movie director, release year, and IMDb rating.

### ⭐ Rate a Movie

- Select a user and movie.
- Submit a rating from 1.0 to 5.0.
- Uses an `INSERT ... ON DUPLICATE KEY UPDATE` operation.
- MySQL triggers automatically recalculate the movie's average user rating.

### 📝 Reviews

- Publish a review for a movie.
- Select a sentiment: Positive, Neutral, or Negative.
- View recent reviews with user, movie, sentiment, and date information.

### ❤️ Favorites

- Select a user and add a movie to their favorites.
- Prevents duplicate favorites through a database constraint.
- Displays the user's saved favorites.

### 📊 Analytics

Includes:

- Movie distribution by language.
- Smart movie scores generated by the `MovieScore` stored function.
- IMDb ranking using a SQL window function.

### 🧪 SQL Query Lab

Provides interactive examples covering:

- Top-rated movies.
- Above-average IMDb ratings.
- Genre statistics using a CTE.
- Language-wise movie ranking using a window function.

Only `SELECT` and `WITH` queries are allowed in the interactive Query Lab.

## 🗄️ Database Design

The CineVerse database is named:

```text
cineverse
```

### Main Tables

| Table | Purpose |
|---|---|
| `users` | Stores user information |
| `movies` | Stores movie details and ratings |
| `directors` | Stores director information |
| `actors` | Stores actor information |
| `genres` | Stores movie genres |
| `movie_genres` | Maps movies to genres |
| `movie_cast` | Maps actors to movies and characters |
| `streaming_platforms` | Stores streaming platform information |
| `movie_platform` | Maps movies to streaming platforms |
| `ratings` | Stores user ratings |
| `reviews` | Stores movie reviews and sentiment |
| `favorites` | Stores users' favorite movies |

### Views

The project also creates:

- `movie_catalog` — consolidated movie information including director and genres.
- `user_rating_summary` — summarizes the number and average rating given by each user.

## ⚙️ Stored Function

CineVerse includes a MySQL function called:

```sql
MovieScore()
```

It combines:

- IMDb rating
- Average user rating
- Popularity

to calculate a weighted **smart score** for each movie.

The application uses this score in the Analytics section to rank movies.

---

## 🔄 Stored Procedure

The project includes:

```sql
GetMoviesByGenre()
```

It accepts a genre name and returns movies belonging to that genre, ordered by IMDb rating.

The Streamlit **Genre Explorer** uses this procedure directly from Python.

---

## ⚡ Triggers

Three triggers maintain the movie's average user rating:

```text
rating_after_insert
rating_after_update
rating_after_delete
```

Whenever a rating is inserted, updated, or deleted, the corresponding movie's `average_user_rating` is recalculated automatically.

This demonstrates how database-level automation can maintain derived data.

## 📁 Project Structure

```text
cineverse_streamlit_project/
│
├── app.py
├── database.py
├── cineverse.sql
├── requirements.txt
├── README.md

```

### File Description

**`app.py`**

- Streamlit application.
- Contains the UI, navigation, filters, forms, charts, and database operations.

**`database.py`**

- Handles the Python-to-MySQL connection.
- Provides helper functions for:
  - Running queries and returning Pandas DataFrames.
  - Executing INSERT/UPDATE/DELETE statements.
  - Calling stored procedures.

**`cineverse.sql`**

- Creates the database and schema.
- Inserts sample data.
- Creates indexes, views, stored function, stored procedure, and triggers.
- Contains SQL examples for the Query Lab.

**`requirements.txt`**

- Lists the Python dependencies required by the application.

# 🚀 Installation & Setup

## 1. Prerequisites

Install:

- Python 3
- MySQL Server
- pip or `uv`

The project works well on Apple Silicon Macs such as **Mac M1/M2/M3/M4** when using native Homebrew/Python installations.

---

## 2. Start MySQL

If MySQL was installed through Homebrew:

```bash
brew services start mysql
```

Check its status:

```bash
brew services list | grep mysql
```

You should see:

```text
mysql started
```

---

## 3. Create the CineVerse Database

From the project directory, run:

```bash
mysql -u scott -p < cineverse.sql
```

Replace `scott` with your MySQL username if necessary.

The SQL script creates the `cineverse` database, tables, views, sample data, stored routines, indexes, and triggers.

> **Important:** The SQL script begins by dropping and recreating the `cineverse` database. Running it again will reset the CineVerse database to the sample-data state.

---

## 4. Configure MySQL Connection

Open:

```text
database.py
```

Configure:

```python
DB_CONFIG = {
    "host": "localhost",
    "user": "scott",
    "password": "YOUR_MYSQL_PASSWORD",
    "database": "cineverse"
}
```

Replace `YOUR_MYSQL_PASSWORD` with the password for your MySQL user.

### Security Note

For a production application, do **not** hard-code database credentials in source code. Use environment variables or a secrets manager instead.

For a college/local project, the current configuration is sufficient as long as the project is not published with a real password.

---

## 5. Create a Virtual Environment

From the project directory:

```bash
python3 -m venv .venv
```

Activate it:

### macOS / Linux

```bash
source .venv/bin/activate
```

You should see:

```text
(.venv)
```

at the beginning of your terminal prompt.

---

## 6. Install Dependencies

Using pip:

```bash
pip install -r requirements.txt
```

Or, if you use `uv`:

```bash
uv pip install -r requirements.txt
```

The project requires:

```text
streamlit
mysql-connector-python
pandas
```

---

## 7. Test the Database Connection

Before starting Streamlit, test the Python-to-MySQL connection:

```bash
python -c "from database import get_connection; c=get_connection(); print('Connected to CineVerse!'); c.close()"
```

Expected output:

```text
Connected to CineVerse!
```

---

## 8. Run the Streamlit Application

With the virtual environment activated:

```bash
streamlit run app.py
```

Streamlit will provide a local URL, normally:

```text
http://localhost:8501
```

Open that address in your browser.

# 🛠️ Troubleshooting

### MySQL connection error

Make sure MySQL is running:

```bash
brew services start mysql
```

Then verify:

```bash
mysql -u scott -p
```

### `ModuleNotFoundError`

Make sure the virtual environment is activated:

```bash
source .venv/bin/activate
```

Then reinstall:

```bash
pip install -r requirements.txt
```

### Streamlit command not found

Activate the environment and run:

```bash
source .venv/bin/activate
```

Then:

```bash
python -m streamlit run app.py
```

### Database does not contain the expected data

Re-run:

```bash
mysql -u scott -p < cineverse.sql
```

Remember that this resets the `cineverse` database to the data defined in the SQL script.
